🛒 E-Commerce Sales Analysis Project

📌 Project Overview

This project focuses on analyzing e-commerce sales data using Excel, PostgreSQL, Python, and Microsoft Power BI. The objective is to understand sales performance, profitability, product trends, and business performance through data analysis and interactive visualizations.

🎯 Project Objectives

- Analyze total sales and profit.
- Identify top-performing products and categories.
- Track monthly sales trends.
- Analyze payment methods and order statuses.
- Understand city-wise sales performance.
- Create an interactive Power BI dashboard.

🛠️ Tools & Technologies

- Microsoft Excel: Data organization and preliminary analysis.
- PostgreSQL: SQL queries, data aggregation, and business analysis.
- Python: Data processing and exploratory data analysis.
- Microsoft Power BI: Interactive dashboards and data visualization.

🔄 Project Workflow

1. Prepare and organize the e-commerce dataset.
2. Clean and validate the data.
3. Analyze sales data using PostgreSQL queries.
4. Process and explore data using Python, if applicable.
5. Build an interactive dashboard in Power BI.
6. Review key metrics and business trends.
